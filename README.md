# OLABERRY Smart Contact Card & NFC Hub

An interactive 3D NFC Smart Business Card website built with GSAP 3D animations and instant contact actions.

## Features
- **GSAP 3D Spin Animation**: The business card performs a 2.0-second 3D spin on page load and smoothly settles to a stop.
- **Two-Sided Smart Card**: Realistic front face with the OLABERRY business card and an executive NFC smart card back with EMV chip and contactless waves.
- **Dynamic Live QR Code**: Generates a live QR code matching the exact hosted URL so smartphone cameras can scan and instantly redirect to this card.
- **Interactive 3D Tilt**: Interactive 3D mouse tracking tilt and specular sheen overlay on hover.
- **Quick Contact Hub**: Direct actions for Call, WhatsApp, Service Booking, Website, Email, Directions, and automatic vCard (`.vcf`) download.
- **Fully Responsive**: Optimized for smartphones, tablets, and desktops.

## Deployment on Netlify
1. Connect this repository to [Netlify](https://app.netlify.com/).
2. Set the publish directory to `.` (root).
3. Click **Deploy Site**.
